## Sistema visual

O MB é um desenho próprio reconstruído em curvas, não texto digitado. A estrutura preserva a leitura sutil de F que Matheus associou à inicial da noiva. A assinatura por extenso usa Sora no peso 600 e caixa baixa, com ponto final laranja. Inter permanece como fonte de leitura do futuro site; não é necessária para abrir os arquivos da logo.

Os SVGs de marca têm letras convertidas em contornos e não dependem de fontes instaladas ou links externos. Não contêm imagens raster embutidas. O PNG é uma renderização do mesmo vetor, sem fundo, textura, brilho ou gradiente.

## Aplicação

- Usar o nome por extenso no cabeçalho clean. O MB pode acompanhar a assinatura ou aparecer sozinho em espaços compactos.
- Preferir as versões claras sobre grafite e as escuras sobre fundos claros. A versão monocromática escura é preferível quando o laranja perder definição sobre um fundo claro.
- Margem de proteção sugerida: 1/4 da altura visível do monograma em todos os lados. A margem deve ser aplicada no layout e pode ser maior que a margem interna do arquivo.
- Mínimo recomendado: 40 px de largura para o monograma comum; 200 px para o nome independente; 280 px para a composição horizontal. Para espaços menores, usar o favicon específico.
- Favicons: usar os arquivos dedicados, que abrem ligeiramente as separações internas. Em 16 px, as curvas têm menos definição; priorizar 32 px ou SVG quando a plataforma permitir.
- Preservar proporções. Não esticar, inclinar, contornar ou adicionar efeitos ao desenho.
- Não redesenhar o símbolo com a fonte Sora. Usar os arquivos SVG fornecidos como referência de produção no Claude.
